# にょろポインタ（Mac用）

Macの画面全体で、6玉の短い黄色いにょろがマウスを追いかける、メニューバー常駐のポインタ補助アプリです。

## クローンから起動まで

**macOS 13 Ventura以降**と **Xcode Command Line Tools** が必要です。ビルド済みの `.app` はリポジトリに含まれていないため、初回は次の手順で作成します。

開発ツールをまだ入れていない場合は、ターミナルで次を実行し、表示されるインストール画面の操作を完了してください。Xcode本体をインストールする必要はありません。

```sh
xcode-select --install
```

準備ができたら、次を順に実行します。

```sh
git clone https://github.com/tahoooo0oo/nyoro-pointer-public.git
cd nyoro-pointer-public
./build.command
open 'にょろポインタ.app'
```

`build.command` は、そのMacの実行環境（Apple Silicon / Intel）向けにアプリを作成し、軌跡のテストを実行します。`PASS:` と「できました」が表示されればビルド完了です。2回目からは生成された `にょろポインタ.app` をダブルクリックするだけで使えます。ソースを更新した場合は再度 `./build.command` を実行してください。

開発ツールの初回導入とクローンにはネット接続が必要ですが、導入後のビルドとアプリの使用に通信や追加ライブラリは不要です。開発ツールの案内は [Appleのインストール手順](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools/) も参照してください。

## 使い方

1. `にょろポインタ.app` をダブルクリックします。
2. メニューバーに「にょろ」が表示されます。
3. マウスを動かすと、普通の矢印に黄色い玉がついてきます。**先頭の玉の中心がクリック位置**です。

- **Control＋Option＋N**：表示／非表示（ほかのアプリを操作中も使用可能）。別アプリのショートカットと競合する場合は、メニューバーから切り替えます。
- 「にょろ」メニュー → **長さ**：3・4・6・8・40玉。初期値は6玉。
- 「にょろ」メニュー → **玉の大きさ**：10・14・18・24 pt。初期値は14 pt。
- **ゲーミングモード（虹色）**：先頭の黄色から、緑・水色・青・紫・ピンクへ変化します。短いにょろでも40玉でも、全体が虹色になります。チェックを外すと通常の黄色に戻ります。色は約4秒で一周し、マウスを止めていてもにょろ全体を虹色が流れ続けます。
- **普通の矢印を隠す（実験機能）**：初期値はオフ。説明ダイアログで明示的に有効にした場合だけ、非公開APIを使って矢印を隠します。オフにすると標準モードへ戻り、次回起動時もオフです。
- **終了（普通のカーソルに戻す）**：終了してカーソルを戻します。

設定メニューを開いている間は、選びやすいように普通のカーソルを表示します。設定は起動ごとに初期値へ戻ります。ログイン時の自動起動は設定しません。

## 実装とビルド

`NyoroPointer.swift` が全ソースです。AppKitの透明なウィンドウに描画し、カーソルの移動を追跡します。透明ウィンドウはクリックを通過させ、キーボード入力も取得しません。CoreGraphicsのカーソル表示回数は、このアプリが隠した分だけ終了時・非表示時に戻します。

ビルドと起動の手順は「クローンから起動まで」を参照してください。Appleの配布用署名・公証は行わず、ローカル実行用のアドホック署名を付けます。生成した `.app` を別のMacへ配布した場合、そのMacのセキュリティ設定により起動が制限されることがあります。

macOS 26.5.2 / Apple Siliconでビルドと軌跡テストを確認しています。Intel MacやほかのmacOSでの実機動作、外部画面・フルスクリーンでの表示は、利用する環境で確認してください。

標準モードは公開APIだけを呼び出し、普通の矢印とにょろを同時に表示します。起動時や実験機能の確認をキャンセルした場合は、非公開APIのシンボル解決・呼び出しを行いません。虹色・長さ変更・表示切替にも非公開APIは不要です。

実験機能を明示的に有効にした場合だけ、このアプリの描画接続に対して、非公開の `CGSSetConnectionProperty` で `SetsCursorInBackground` を設定します。シンボルが見つからない場合や設定が失敗した場合は標準モードを保ちます。ただし、非公開APIの仕様変更による異常終了やカーソル表示の不具合まで防げるわけではありません。オフにする際は矢印を戻して背景カーソル設定を解除します。通常終了時も復元しますが、強制終了などでは復元処理の実行を保証できません。

実験機能を含むこのコードは、公開APIのみを認めるMac App Store向けではありません。GitHubでのソース公開とは別の条件です。

システムファイルや他アプリの設定は変更しません。カーソル位置を読み、表示するだけで、入力内容の記録・通信・画面収録は行いません。

参考：Appleの [CGDisplayHideCursor](https://developer.apple.com/documentation/coregraphics/cgdisplayhidecursor(_:)) は通常、前面アプリからの利用を想定しています。背景アプリでのプロセス単位の設定は [CursorHide](https://github.com/ggreer/CursorHide/blob/master/CursorHide/AppDelegate.m) の使用例を参考に、利用可否を確認する実装にしています。
